# 随访采集助手

面向基层入户随访的离线优先 PWA。用于采集原发性高血压、2 型糖尿病随访信息，并导出结构化 JSON/CSV，供电脑端录入桥接器读取。

## 特点

- 手机浏览器安装，断网可用
- 6 位以上本地密码加密，数据不上传服务器
- 录入顺序按基本公卫随访表组织
- 自动计算 BMI，提供必填项和数值范围校验
- 导出 JSON、按病种导出 CSV
- 电脑端桥接器默认只生成录入计划；平台保存动作永久保留人工确认

## 本地运行

```powershell
pwsh -NoProfile -File .\scripts\serve.ps1
```

浏览器打开 `http://127.0.0.1:4173`。

## 数据安全

应用使用 Web Crypto API（PBKDF2 + AES-GCM）加密浏览器本地数据。密码不会保存或上传。遗忘密码无法恢复数据，请定期导出加密备份或结构化数据。
